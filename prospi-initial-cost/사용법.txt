PROSPI 초기 코스트 — v0.1

Windows 10/11 64비트용 단일 실행 파일입니다. Python, Cheat Engine, 별도 .NET 설치는 필요하지 않습니다.

포함된 기능
1. 스타플레이어 어필 코스트 차감 방지
2. 스타플레이어 신규 선수 초기 능력치 코스트 차감 방지

사용 순서
1. 다른 에디터의 같은 차감 방지 기능을 모두 끕니다.
2. 게임에서 원하는 스타플레이어 초기 설정 화면을 엽니다.
3. ProspiInitialCost.exe를 실행하고 '게임 연결 / 다시 검색'을 누릅니다.
4. '명령 확인됨'으로 표시된 해당 기능을 켭니다.
5. 게임에서 선택 항목을 변경하여 남은 코스트가 차감되지 않는지 확인합니다.
6. 초기 설정 화면을 떠나기 전에 '둘 다 끄기 / 원래 코드 복원'을 누릅니다.

연결 대상은 prospi-Win64-Shipping.exe입니다.
어필 기능과 초기 능력치 기능은 서로 독립적으로 켜고 끌 수 있습니다.
기존에 소모한 코스트를 채우거나, 최대 코스트를 늘리는 기능은 아닙니다.
오리지널 선수 전용 코스트 최대값 유지 기능은 포함하지 않았습니다.

동작
실행 중인 게임 주 모듈의 실행 코드 영역을 검색합니다.
각 기능은 주변 명령까지 맞는 후보가 정확히 한 개일 때만 사용할 수 있습니다.
게임 2.1.0 관련 분석에서 확인한 패턴을 사용하며, 다른 버전에서는 현재 명령 일치 여부를 확인합니다.
기능을 켜면 해당 6바이트 명령을 무효화하고, 끄면 이번 실행에서 읽어 둔 원래 명령으로 복원합니다.
다른 툴이 이미 해당 위치를 변경했거나 후보가 모호하면 해당 기능을 사용하지 못하도록 합니다.
생성 화면 자동 판별은 포함하지 않았으므로 사용할 화면은 직접 확인해 주세요.

종료
정상 종료 시 켜진 기능을 복원합니다. 복원 실패 시 창을 유지하고 안내합니다.
프로그램을 강제 종료하면 복원 절차를 실행할 수 없습니다. 이 경우 게임을 재시작해야 원래 코드로 돌아갑니다.
게임 종료를 감지하면 연결과 이전 주소를 버리며, 다음 실행에는 다시 검색해야 합니다.

검증 범위
Windows x64 GUI 실행 파일 빌드와 PE 형식, 시스템 DLL 의존성을 확인했습니다.
두 패턴의 탐지, 경계 분할, 중복 후보, 이미 변경된 명령, 불완전한 데이터의 판별 테스트를 통과했습니다.
실제 Windows 실행, 게임 연결, 기능 적용 및 복원은 이 제작 환경에서 검증하지 못했습니다.

게임 파일 자체와 제3자 에디터 실행 파일은 수정하지 않습니다.
